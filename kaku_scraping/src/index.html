候補から選んで登録

下のリンクをブラウザのブックマークバーへドラッグしてください。カクヨムの 「閲覧履歴」・ 「未読あり」、または小説家になろうの 「ブックマーク」を開いた状態でそのブックマークをクリックすると、 新しいタブが開き、作品一覧（URL・タイトル・未読話数・全話数）の JSON が全選択された状態で表示されます。コピー（Ctrl+C / Cmd+C）して、下の欄に貼り付けてください。 なろうはブックマークの残りのページも自動で読み込み（1 秒間隔）、しおりを挟んだ話を開始話数の初期値にします。

📥 作品一覧を抽出（カクヨム / なろう） （この画面でクリックすると動作確認。カクヨム・なろうのページではないので「0 件」と出れば正常）

ドラッグがうまくいかない場合（手動でブックマークを作る / コンソールに貼り付ける）

手動でブックマークを作る: 下の「URLを全選択」を押して Ctrl+C（Cmd+C）でコピーし、 Chrome のブックマークマネージャ（Ctrl+Shift+O）→ 右上の「⋮」→「新しいブックマークを追加」で、 URL 欄にそのまま貼り付けてください（名前は任意）。ドラッグ＆ドロップを経由しないぶん確実です。

コンソールに貼り付ける: 同じ処理を kaku_scraping/tools/extract_antenna_list.js としてリポジトリにも置いています。 カクヨム・なろうの対象ページを開いた状態でブラウザの開発者ツール（F12）のコンソールにその中身を貼り付けて実行しても、同じ結果が得られます。
